1. 程序如何运行 / How programs run

核心解释

程序是一组让计算机执行任务的符号和规则。课件区分 system programs（操作系统、编译器）和 application programs（文字处理、表格等）。语言层次可从 high-level language 经过 assembly language 到 machine language。

English

A program is a set of instructions that tells computer hardware what to do. System programs support the computer; application programs serve users.

Compiler

先把整个 source program 翻译成 machine code，再执行。适合记忆：translate first, run later。

Interpreter

执行过程中逐步翻译代码。适合记忆：translate while running。

Linker

把多个模块和库连接起来，解决对其他代码的引用，生成可执行程序。

文件类型：source program 是程序员写的代码；object program 是编译输出；executable program 是链接库之后可运行的程序。

2. 变量、类型与运算 / Variables, types, operators

变量名保存一个值；Python 自动识别类型，变量名区分大小写。= 是 assignment：先计算右边，再把结果放进左边的 variable。

a = 15
b = 2.5
name = "Ana"
passed = True
print(type(a), type(b), type(name), type(passed))
OperatorMeaningEnglish sentence
/普通除法，通常得到 float“Slash performs ordinary division.”
//floor division，向下取整“Double slash performs floor division.”
%remainder，余数“Percent returns the remainder.”
**power/exponentiation，幂“Double star raises a number to a power.”
英文模板 / Answer frame: “The output is ___. The program evaluates ___ first and assigns the result to ___.”

3. 字符串 / Strings

String 是字符序列，可以用单引号或双引号创建。+ 拼接，* 重复；replace 替换，转换成 list 可以逐字符处理。

text = "Python"
print(text + " review")
print("ha" * 3)
print(text.replace("P", "p"))
letters = list(text)

A string is a sequence of characters. Concatenation joins strings; repetition repeats a string.

5. 函数 / Functions

函数把一组操作命名起来，在需要时调用。参数可以有默认值；命名参数可以改变传入顺序，但必须放在位置参数之后。

def classify(score, pass_mark=50):
    if score >= pass_mark:
        return "pass"
    return "review"

print(classify(68))
print(classify(score=45, pass_mark=60))

A function takes inputs, performs operations, and returns an output. The return statement sends a value back to the caller.

6. 控制流与错误 / Control flow and errors

if/else

根据 condition 决定执行哪一段代码。

for

按顺序遍历一个 sequence，每轮变量取下一个值。

while

只要 condition remains true，就反复执行。

break/continue

break 结束循环；continue 结束本轮并进入下一轮。

try/except

捕获可能发生的 runtime exception，避免程序直接崩溃。

for n in [1, 2, 3, 4]:
    if n == 3:
        continue
    print(n)

try:
    value = int("abc")
except ValueError:
    print("Invalid input")
ErrorMeaning
Syntax error违反语言语法，例如括号或缩进错误。
Runtime error运行时发生，例如除以零或输入无效。
Logical error程序运行却产生错误结果。

7. 基础代码：写法、用途与输出 / Code, use, output

读代码时固定按四步：先看输入值，再按执行顺序跟踪变量，然后判断函数或方法是否修改原对象，最后写出输出。Read the inputs, trace execution, check mutation, and then state the output.

赋值与算术

score = 7
score = score + 3
print(score)
print(15 / 2)
print(15 // 2)
print(15 % 2)
输出 / Output
10
7.5
7
1

score = score + 3 先读取旧值 7，计算右侧 10，再把 10 赋给左侧变量。/ 是普通除法，// 是 floor division，% 是 remainder。

切片、append 与 extend

items = [10, 20, 30, 40]
print(items[1:3])
items.append([50, 60])
print(items)

other = [10, 20]
other.extend([30, 40])
print(other)
输出 / Output
[20, 30]
[10, 20, 30, 40, [50, 60]]
[10, 20, 30, 40]

Slice 的 stop 不包含在结果中。append 把整个参数当作一个元素；extend 把参数中的元素逐个加入。

函数、默认参数与 keyword argument

def total(price, quantity=2):
    return price * quantity

print(total(5))
print(total(quantity=3, price=4))
输出 / Output
10
12

第一次使用默认 quantity=2；第二次用参数名传值，所以 named arguments 可以交换顺序。位置参数必须放在 keyword arguments 之前。

循环、continue 与 break

for n in range(5):
    if n == 2:
        continue
    if n == 4:
        break
    print(n)
输出 / Output
0
1
3

continue 跳过 n=2 这一轮的 print；break 在 n=4 时结束整个循环。

常见考试要求：不要只写最终输出。简答题可写：“The loop prints 0, 1, and 3. The value 2 is skipped by continue, and the loop terminates when n becomes 4.”

10. 课件代码截图中的高频陷阱

知识点必须会判断English frame
赋值顺序先计算右侧 expression，再把结果绑定到左侧 variable；右侧使用的是赋值前的当前值。The right-hand side is evaluated first, and the result is assigned to the variable.
break立即结束最内层循环，循环后面的语句继续执行。Break terminates the nearest enclosing loop.
continue跳过当前 iteration 剩余语句，进入下一轮。Continue skips the rest of the current iteration.
while True 验证不断读取输入；有效时 break，无效时提示后重试。The loop repeats until valid input is entered.
Mutable / immutablelist、dict、set 可原地改变；int、float、bool、str、tuple 不可原地改变。A list is mutable, whereas a tuple is immutable.
sort / sortedlist.sort() 修改原 list 并返回 None；sorted(x) 返回新 list。Sort changes the original list; sorted returns a new list.
简答组织：先写发生了什么，再写原因。“The output is ___. This happens because Python evaluates ___ before ___.”

11. 剩余正式课件考点 / Remaining lecture points

TopicCourse pointExam distinction
Program categoriesSystem programs 支撑计算机运行，如 operating system、compiler；application programs 为用户完成任务，如 word processor、spreadsheet。按服务对象区分，不按编程语言区分。
Language levelsHigh-level language → compiler/assembler/interpreter → machine language → hardware switches/gates。Assembly 使用 mnemonic symbols；machine language 使用 binary digits。
C / C# / Java / JavaScript / PythonC 与 UNIX 历史相关；C# 与 .NET/CLI 相关；Java 强调跨平台运行环境；JavaScript 可在网页环境执行；Python 强调可读性、较少代码和快速开发。Java 和 JavaScript 不是同一种语言。
Variable names名称区分大小写；由 letters、digits、underscore 构成；不能以 digit 开头；不能使用 Python keyword。score 与 Score 是两个变量。
Type conversionint()、float()、str()、bool() 建立新类型值；type(x) 查询类型。/ 通常返回 float；conversion 可能因无效文本产生 ValueError。
Collection detailsList 可混合类型；tuple 可用于函数返回多个值；dict 由 key:value 映射；set 保存 unique values，适合 membership 和去重。Set 无位置索引；dict 查找使用 key；slice 的 stop 不包含在结果中。
Data/AI examples课件用 data availability、analytics、automation、Deep Blue、Watson、AlphaGo 和 humanoid robots 说明程序与 AI 的现实应用。这些是导论案例，不代表 Week 1 只考 AI。

12. Week 1 图片题考点 / Visual-question checklist

课件图片类型看图时先找什么可能要求
Compiler / interpreter 流程图source code、translation、machine code、execution 的先后关系。比较“translate complete program first”与“translate and execute statement by statement”。
CPU fetch-decode-execute 图instruction 与 data 在 fetch、decode、retrieve、execute、store 中的流向。按正确顺序排列阶段，说明每一步职责。
变量和算术输出截图右侧 expression、运算符优先级、结果类型。预测 /、//、%、** 的值和类型。
List / tuple / dict / set 截图括号形式、索引方式、mutable、ordered、unique。识别数据结构，判断修改后输出或选择合适容器。
函数与参数错误截图def、parameter、return、default value、调用顺序。指出 positional argument follows keyword argument 的原因并改正。
Loop / exception 截图每轮变量值、condition、缩进、break/continue/except 的跳转位置。逐行追踪输出，区分 syntax、runtime 和 logical error。
看图答题顺序：先写“图中对象是什么”，再写“箭头或代码怎样变化”，最后写“因此输出/结论是什么”。

13. 可能的考试问法 / Possible exam prompts

MCQ / True-False
  • 判断 compiler、interpreter、linker 的正确顺序或描述。
  • 区分 syntax、runtime、logical error。
  • 判断变量名是否合法、表达式结果类型是什么。
  • 判断 list/tuple/set/dict 的 mutable、ordered、unique 性质。
  • 判断 append、extend、sort、sorted 的结果。
Short question
  • 跟踪一段含 assignment、if、loop、break/continue 的输出。
  • 用英文比较 compiler 与 interpreter。
  • 解释一个 slice 的 start、stop、step。
  • 写一个带 positional/default/keyword arguments 的函数调用并说明顺序。
  • 说明 try/except 为什么不会让程序直接崩溃。

这些是根据正式课件与官方题型整理的自测方向，不是官方题目或题量预测。
