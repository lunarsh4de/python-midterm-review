1. 程序如何运行 / How programs run

核心解释

程序是一组让计算机执行任务的符号和规则。课件区分 system programs（操作系统、编译器）和 application programs（文字处理、表格等）。语言层次可从 high-level language 经过 assembly language 到 machine language。

English

A program is a set of instructions that tells computer hardware what to do. System programs support the computer; application programs serve users.

Compiler

先把整个 source program 翻译成 machine code，再执行。适合记忆：translate first, run later。

Interpreter

执行过程中逐步翻译代码。适合记忆：translate while running。

Linker

把多个模块和库连接起来，解决对其他代码的引用，生成可执行程序。

文件类型：source program 是程序员写的代码；object program 是编译输出；executable program 是链接库之后可运行的程序。

2A. 课件基础算术运算与输出 / Arithmetic operations and output

课件列出的基础算术运算包括赋值、加法、减法、乘法、普通除法、floor division、幂和余数。考试常把运算符、结果值和结果类型放在同一道代码输出题中。

变量命名规则 / Variable-name rules：变量名区分大小写，由 letters、digits 和 underscore 构成，不能以 digit 开头，也不能使用 Python keyword。Names are case-sensitive, may contain letters, digits, and underscores, cannot start with a digit, and cannot be Python keywords. For example, score and Score are different names.

3. 字符串 / Strings

String 是字符序列，可以用单引号或双引号创建。+ 拼接，* 重复；replace 替换，转换成 list 可以逐字符处理。

text = "Python"
print(text + " review")
print("ha" * 3)
print(text.replace("P", "p"))
letters = list(text)

A string is a sequence of characters. Concatenation joins strings; repetition repeats a string.

5. 函数 / Functions

函数把一组操作命名起来，在需要时调用。参数可以有默认值；命名参数可以改变传入顺序，但必须放在位置参数之后。

def classify(score, pass_mark=50):
    if score >= pass_mark:
        return "pass"
    return "review"

print(classify(68))
print(classify(score=45, pass_mark=60))

A function takes inputs, performs operations, and returns an output. The return statement sends a value back to the caller.

5A. 函数的 docstring 与多返回值 / Docstrings and multiple returns

Docstring / 文档字符串

def double(x):
    """Return twice x."""
    return x * 2

print(double(4))
输出 / Output: 8

三引号字符串可以说明函数用途。A docstring documents the purpose of a function.

Multiple return values / 多返回值

def min_max(values):
    return min(values), max(values)

low, high = min_max([3, 1, 5])
print(low, high)
输出 / Output: 1 5

Python 实际返回一个 tuple，可以拆包到两个变量。Python returns a tuple, which can be unpacked into two variables.

6. 控制流与错误 / Control flow and errors

if/else

根据 condition 决定执行哪一段代码。

for

按顺序遍历一个 sequence，每轮变量取下一个值。

while

只要 condition remains true，就反复执行。

break/continue

break 结束循环；continue 结束本轮并进入下一轮。

try/except

捕获可能发生的 runtime exception，避免程序直接崩溃。

for n in [1, 2, 3, 4]:
    if n == 3:
        continue
    print(n)

try:
    value = int("abc")
except ValueError:
    print("Invalid input")
ErrorMeaning
Syntax error违反语言语法，例如括号或缩进错误。
Runtime error运行时发生，例如除以零或输入无效。
Logical error程序运行却产生错误结果。

6A. while 与 if 的输出追踪 / Tracing while and if

n = 1
total = 0
while n <= 3:
    if n % 2 == 1:
        total += n
    n += 1
print(total)
输出 / Output: 4

循环依次检查 1、2、3；只有奇数 1 和 3 加入 total。The loop checks 1, 2, and 3; only the odd values 1 and 3 are added to total.

Exam wording / 考试句型：“The while loop repeats while the condition is true. The if statement controls which values are added.”

7. 基础代码：写法、用途与输出 / Code, use, output

读代码时固定按四步：先看输入值，再按执行顺序跟踪变量，然后判断函数或方法是否修改原对象，最后写出输出。Read the inputs, trace execution, check mutation, and then state the output.

赋值与算术

score = 7
score = score + 3
print(score)
print(15 / 2)
print(15 // 2)
print(15 % 2)
输出 / Output
10
7.5
7
1

score = score + 3 先读取旧值 7，计算右侧 10，再把 10 赋给左侧变量。/ 是普通除法，// 是 floor division，% 是 remainder。

切片、append 与 extend

items = [10, 20, 30, 40]
print(items[1:3])
items.append([50, 60])
print(items)

other = [10, 20]
other.extend([30, 40])
print(other)
输出 / Output
[20, 30]
[10, 20, 30, 40, [50, 60]]
[10, 20, 30, 40]

Slice 的 stop 不包含在结果中。append 把整个参数当作一个元素；extend 把参数中的元素逐个加入。

函数、默认参数与 keyword argument

def total(price, quantity=2):
    return price * quantity

print(total(5))
print(total(quantity=3, price=4))
输出 / Output
10
12

第一次使用默认 quantity=2；第二次用参数名传值，所以 named arguments 可以交换顺序。位置参数必须放在 keyword arguments 之前。

循环、continue 与 break

for n in range(5):
    if n == 2:
        continue
    if n == 4:
        break
    print(n)
输出 / Output
0
1
3

continue 跳过 n=2 这一轮的 print；break 在 n=4 时结束整个循环。

常见考试要求：不要只写最终输出。简答题可写：“The loop prints 0, 1, and 3. The value 2 is skipped by continue, and the loop terminates when n becomes 4.”

10. 课件代码截图中的高频陷阱

知识点必须会判断English frame
赋值顺序先计算右侧 expression，再把结果绑定到左侧 variable；右侧使用的是赋值前的当前值。The right-hand side is evaluated first, and the result is assigned to the variable.
break立即结束最内层循环，循环后面的语句继续执行。Break terminates the nearest enclosing loop.
continue跳过当前 iteration 剩余语句，进入下一轮。Continue skips the rest of the current iteration.
while True 验证不断读取输入；有效时 break，无效时提示后重试。The loop repeats until valid input is entered.
Mutable / immutablelist、dict、set 可原地改变；int、float、bool、str、tuple 不可原地改变。A list is mutable, whereas a tuple is immutable.
sort / sortedlist.sort() 修改原 list 并返回 None；sorted(x) 返回新 list。Sort changes the original list; sorted returns a new list.
简答组织：先写发生了什么，再写原因。“The output is ___. This happens because Python evaluates ___ before ___.”

10A. 课件补充：Jupyter、编程过程与语言层级 / Jupyter, process, and language levels

高级语言、汇编语言、机器语言 / High-level, assembly, machine

三层不要混淆：高级语言更接近人类表达；汇编语言使用 mnemonic symbols；机器语言直接使用 binary digits（0 和 1），由硬件执行。High-level languages are closer to human expression; assembly uses mnemonic symbols; machine language uses binary digits and is executed by the CPU.

层级 / Level课件特征 / Course feature转换工具 / Translator可能考点 / Exam focus
High-level language 高级语言Python、C++、Java、JavaScript；可读性较高。Readable and relatively concise.compiler 或 interpreter更容易编写、阅读和维护，但不能直接作为 CPU 指令执行。Easier to write and maintain, but not directly executed by the CPU.
Assembly language 汇编语言用 mnemonic symbols 表示低层指令，例如操作码和寄存器名称。Uses mnemonic symbols for low-level instructions.assembler比高级语言更接近硬件。Closer to hardware than a high-level language.
Machine language 机器语言由 binary digits（0/1）组成，CPU 可以直接执行。Consists of binary digits and can be executed directly by the CPU.不需要再翻译成更低层指令 / no further translation题目可能给出 0/1 或 hardware switches/gates，让你识别 machine language。Identify it from binary digits or hardware switches and gates.
顺序题模板 / Sequence frame：“A high-level program is translated into assembly or machine instructions. An assembler converts assembly language into machine language, and the CPU executes machine language.”
