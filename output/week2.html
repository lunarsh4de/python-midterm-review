1. NumPy：从 list 到 array / Arrays

NumPy 是 scientific computing 的基础库。数组的元素通常使用兼容的 common dtype，因此比普通 list 更适合向量化计算。

属性 / Attributes

ndim 是维度数量；shape 是每个 axis 的大小；size 是元素总数；dtype 是元素类型。

轴 / Axes

二维数组中 axis 0 表示行方向，axis 1 表示列方向。sum(axis=0) 压掉行，结果每列一个。

向量化 / Vectorization

数组运算一次作用于整个数组，减少 Python 层循环，利用同质数据提升效率。

import numpy as np
a = np.array([[2, 4, 6], [1, 3, 5]])
print(a.ndim, a.shape, a.size, a.dtype)
print(a.sum(axis=0))
print(a.sum(axis=1))

英文：“Axis 0 reduces down the rows and returns one result per column.” / “Axis 1 reduces across the columns and returns one result per row.”

splitconcatenate 的反向操作。分割数与长度不匹配。

3. 索引、mask 与 broadcasting / Indexing and broadcasting

a = np.array([[5, 6, 8], [1, 6, 4]])
print(a[0, 2])
print(a[:, 1])
mask = a > 5
print(a[mask])
a[a < 5] = 0

b = np.array([10, 20, 30])
print(a + b)  # compatible shapes are broadcast

Broadcasting 是把兼容的 shape“扩展”到可以逐元素计算；Boolean mask 用 True/False 选择满足条件的元素；fancy indexing 用索引数组选择多个位置。

“Broadcasting stretches compatible shapes for element-wise operations. A Boolean mask selects elements that satisfy a condition.”

排序 / Sorting

np.sort 返回排序结果；高维数组可以指定 axis。np.argsort 返回排序后的索引，而不是排序值。

5. SciPy：科学计算工具箱 / Scientific computing

SciPy built on NumPy。NumPy 主要提供数组和基础操作；SciPy 进一步提供数学与科学算法。

Subpackages

cluster clustering；constants constants；fftpack Fourier；integrate integration/ODE；linalg linear algebra；optimize optimization/root finding；interpolate interpolation；stats distributions/statistics。

帮助函数 / Help

help() 查看信息；info() 查看对象信息；source() 查看 Python 对象的源码。

Lambda

lambda 是一次性匿名函数，适合短小的高阶函数输入。

from scipy import integrate, optimize, interpolate
value, error = integrate.quad(lambda x: x, 0, 1)
result = optimize.minimize(lambda x: (x - 3)**2, x0=0)
# fft/ifft: discrete Fourier transform and inverse
# linalg: inverse and other matrix operations

插值是在已知点之间构造新点；曲线拟合寻找最贴近一组数据点的数学函数。

6. Pandas：有标签的数据表 / Labelled data

DataFrame 是二维结构，列有名字、行有 index；Series 是 DataFrame 的一列，即一维结构。Iris dataset 例子中，每行是一个 sample，每列是一个 feature，species 是 label。

print(df.describe())

TermMeaning
loc按显式 label 访问行列。
iloc按整数位置访问行列。
describe()默认提供数值列 summary statistics。

inplace是否直接修改原 DataFrame。

统计工具包括 mean、standard deviation、median、mode、counts，以及按类别分组比较。英文：“A DataFrame is a two-dimensional labelled data structure.”

先读懂 import 和缩写

SciPy：计算积分

from scipy.integrate import quad

area, error = quad(lambda x: x**2, 0, 1)
print(round(area, 3))
输出 / Output
0.333

lambda x: x**2 表示函数 x²；0 和 1 是积分上下限。quad 返回估计值与误差估计，所以用两个变量接收。

OperationMeaningExam trap
reshape改变 shape，不改变元素总数。新维度乘积必须等于 size。
concatenate沿已有 axis 连接。除连接轴外，其余维度必须匹配。

argsort返回排序后元素对应的原索引。返回 indices，不是已排序值。

13. 定义与工具补漏

Data visualization

Data visualization 是以 pictorial or graphical format 呈现数据，使人更容易发现 pattern、trend、comparison 和 relationship。图表类型必须由变量类型与问题决定，而不是只看外观。

Data visualization presents data graphically so that patterns and relationships are easier to understand.

NumPy vs SciPy

NumPy 提供高效 n-dimensional arrays、indexing、sorting 和基础 numerical operations；SciPy 建立在 NumPy 上，提供更专门的 scientific algorithms。

SciPy builds on NumPy and adds specialised scientific routines.

SciPy inspection helpers

help(obj) 查看一般帮助；scipy.info(obj) 在旧版课件中用于说明；scipy.source(obj) 用于查看 Python 实现源码。现代环境通常使用 help、inspect.getsource 和官方文档。

Interpolation

根据已知 data points 估计区间内新点，常强调“在已有点之间”。

Interpolation estimates values between known observations.

Curve fitting

选择一个模型函数并估计 parameters，使曲线总体最好地拟合数据；不要求经过每个点。

Curve fitting estimates model parameters that best match the observations.

Pandas 索引与构造陷阱

  • DataFrame 可由 2-D NumPy array、column Series/dictionary 或 row records 创建。
  • 筛选/删除后 explicit index labels 通常不会自动重新编号；需要时调用 reset_index()。
  • loc 始终按 explicit labels；iloc 始终按 implicit integer positions。
  • 删除列时 axis=1；inplace=True 修改原对象，否则返回新 DataFrame。
  • describe() 默认总结 numeric columns；类别列常用 value_counts()、mode() 或 group statistics。

18A. NumPy 课件补全：创建、组合与输出 / NumPy lecture supplement

PDF 中最容易变成代码输出题的三个问题是：输入的 shape 是什么？函数改变的是值、维度还是索引？返回的是 array、tuple 还是新对象？For every NumPy question, identify the input shape, the operation, and the type and shape of the returned object.

函数 / Function用途 / Use典型结果 / Typical result
zeros、ones、full创建固定值数组；empty 只分配内存，初值未定义；eye 创建单位矩阵。np.eye(2) → [[1.,0.],[0.,1.]]
arange vs linspacearange(start, stop, step) 通常不含 stop；linspace(start, stop, num) 指定数量，默认含 endpoint。arange(0,5,2) → [0 2 4]；linspace(0,1,3) → [0. 0.5 1.]
randomrandom 是 [0,1) 均匀分布；normal 正态分布；randint 整数。seed 固定伪随机序列，便于复现。
reshape重新解释 shape，元素总数不变。np.arange(6).reshape(2,3).shape → (2,3)
concatenate、stack、split前者沿已有 axis 连接；stack 新增 axis；split 是 concatenate 的逆操作。np.split(np.arange(6),3) → 三个长度为 2 的数组。

可复现随机数 / Reproducibility

import numpy as np
np.random.seed(4)
r = np.random.randint(0, 10, size=(2, 3))
print(r.shape)
print(r)

相同 seed 和调用顺序会得到相同序列。A seed makes pseudo-random output reproducible.

切片赋值 / Slice assignment

a = np.arange(6)
a[1:4] = 99
print(a)
[ 0 99 99 99 4 5]

切片赋值会改变原数组选中的元素。Slice assignment changes the selected elements in the original array.

课件定义 / Definition： homogeneous dtype 使数组元素类型兼容并支持 vectorized operations；向量化一次处理整个 array，减少 Python-level loops。Homogeneous arrays enable vectorized operations and reduce Python-level loop overhead.

18B. NumPy 输出题：聚合、mask、排序与矩阵 / Output questions

聚合与 axis / Aggregation

a = np.array([[1, 2, 3], [4, 5, 6]])
print(a.sum())
print(a.sum(axis=0))
print(a.mean(axis=1))
print(a.max(axis=0))
21 [5 7 9] [2. 5.] [4 5 6]

axis=0 得到每列一个结果；axis=1 得到每行一个结果。Axis 0 returns one value per column; axis 1 returns one value per row.

Mask 与计数 / Mask and counting

a = np.array([-2, 0, 3, 5])
m = a > 0
print(m)
print(a[m])
print(np.sum(m))
a[a < 0] = 0
print(a)
[False False True True] [3 5] 2 [0 0 3 5]

True 可当作 1、False 可当作 0。A Boolean mask selects values and can also be counted.

代码 / Code返回 / Returns陷阱 / Trap
a[[3,0,2]]fancy indexing 的新数组索引可乱序，不是连续 slice
np.sort(a)排序后的值不等于 argsort
np.argsort(a)排序后元素的原索引[30,10,20] → [1,2,0]
A @ B矩阵乘法A * B 是逐元素乘法
np.linalg.solve(A,b)求解 Ax=b不是直接返回逆矩阵

English frame: “The Boolean comparison is applied element-wise. The mask keeps entries for which the condition is True, and the aggregation is computed along the specified axis.”

积分 / Integration

from scipy.integrate import quad
value, error = quad(lambda x: x**2, 0, 1)
print(round(value, 3))
0.333

lambda 是一次性匿名函数；第一个返回值是积分估计，第二个是误差估计。

最小化 / Minimization

from scipy.optimize import minimize
f = lambda x: (x[0] - 3)**2
result = minimize(f, x0=[0])
print(round(result.x[0], 1))
print(round(result.fun, 1))
3.0 0.0

x0 是 initial guess；result.x 是参数，result.fun 是目标值。

插值 vs 拟合 / Interpolation vs fitting

Interpolation估计已知点之间的新值，通常通过已知点。
Curve fitting估计模型参数使整体误差较小，不必经过每个点。

Interpolation estimates values between known points; curve fitting estimates parameters for the overall trend.

import pandas as pd
