知识点概括 / Knowledge overview

Assignment 2 的 20 个任务练习数据读取和探索分析：导入库、加载 CSV、查看头尾、shape、数值统计、缺失值、删除行列、列名、筛选、unique/value counts、柱状图和散点图。

The assignment practises a standard exploratory data analysis workflow with Pandas and Matplotlib.

边界 / Boundary

它是数据工具应用练习，不是完整考试范围。天气 CSV 的完整内容没有嵌入资料，具体统计数值属于资料未知。

1. 数据集结构 / Dataset

WeatherHistory.csv 是 Szeged, Hungary 2006–2016 的 hourly/daily summary。资料列包括 Formatted Date、Summary、Precip Type、Temperature、Apparent Temperature、Humidity、Wind Speed、Wind Bearing、Visibility、Loud Cover、Pressure、Daily Summary。

3. 推荐代码骨架 / Code skeleton

df = pd.read_csv("weatherHistory.csv")
print(df.head(6))
print(df.tail(3))
print(df.shape)
print(df.describe())
print(df.isnull().any())
print(df.isnull().sum())
print(df.isnull().sum().sum())
print(df[df.isnull().any(axis=1)])

clean = df.dropna()
without_precip = df.drop("Precip Type", axis=1)
print(df.columns)

selected = df[["Temperature (C)", "Apparent Temperature (C)"]]
hot = df.loc[
    df["Temperature (C)"] > 35,
    ["Temperature (C)", "Humidity", "Wind Speed (km/h)"]
]

counts = df["Summary"].value_counts()
counts.plot(kind="bar", title="Summary")
plt.scatter(df["Temperature (C)"], df["Apparent Temperature (C)"])
plt.title("Apparent Temperature vs Temperature")
plt.show()
