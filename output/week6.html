1. Clustering 基础 / What is clustering?

Clustering 把相似对象放在同一组，使组内相似度 high、组间相似度 low。它用于 marketing、insurance、land use、seismic studies、recommendation 和 anomaly detection。

TypeMeaning
Exclusive一个对象只属于一个 cluster；K-means 属于此类。
Overlapping / fuzzy对象可与多个 cluster 有不同关联度；C-means 是例子。
Hierarchicalcluster 之间有 parent/child 层次关系。

2. Distance measures / 距离

MeasureIdeaMemory
Euclidean平方差求和再开方，普通直线距离。straight line
Squared Euclidean平方差求和，不开方。same without root
Manhattan各坐标绝对差之和。grid/axis path
Cosine用 dot product 和向量范数求 cosine similarity；distance = 1 − similarity。direction

The distance measure determines similarity and influences the shape of clusters.

3. K-means：分配与更新 / Assign and update

  1. Choose k and initialize k centroids。
  2. 计算每个 point 到每个 centroid 的距离，分到最近的 cluster。
  3. 把每个 cluster 的 centroid 更新为其成员的 mean。
  4. 若 centroid 或 membership 变化，重复第 2、3 步；否则停止。
choose k
initialize centroids
repeat:
    assign each point to its nearest centroid
    update each centroid to the mean of its cluster
until assignments stop changing
英文简答模板： “K-means partitions n objects into k clusters. It alternates between assigning each point to the nearest centroid and recomputing centroids as cluster means. It stops when assignments or centroids no longer change.”

4. K-means 截图补充：怎样完成一轮手算

手算草稿格式

Point | d(C1) | d(C2) | chosen cluster
A     | ...   | ...   | ...
B     | ...   | ...   | ...

new C1 = mean(points assigned to C1)
new C2 = mean(points assigned to C2)

所有距离必须使用同一种 metric。若题目要求 one epoch，就完成一次 assignment 和一次 centroid update；不要擅自继续到收敛。

Euclidean: d(x,y)=√Σ(xᵢ−yᵢ)²
Squared Euclidean: Σ(xᵢ−yᵢ)²
Manhattan: Σ|xᵢ−yᵢ|
Cosine distance: 1 − (x·y)/(||x|| ||y||)

Scale warning：如果一个 feature 的数值范围远大于其他 feature，它会支配 Euclidean/Manhattan distance，因此聚类前常需 scaling。

5. 选择 k 与优缺点 / Choosing k and limitations

课件介绍 visual inspection 和 elbow method。SSE 是点到所属 centroid 的 squared distance 总和；随着 k 增大 SSE 通常下降，elbow 是下降突然变缓的位置。

SSE = Σ over clusters Σ over points in cluster distance(point, centroid)²

Pros

Simple、fast、可收敛到 within cluster squared error 的 local minimum。

Cons

需要选择 k；对 initial centers 和 outliers 敏感；偏好 spherical clusters；需要考虑 scaling。

6. Hierarchical clustering / 层次聚类

Hierarchical clustering 产生 nested sequence 和 dendrogram。

Agglomerative

Bottom up：每个点先是一个 cluster，再反复合并最近的两个。

Start with singleton clusters and merge upward.

Divisive

Top down：所有点先在一个 cluster，再反复拆分。

Start with one cluster and split downward.

LinkageCluster distance
Single link两簇成员之间的最小距离。
Complete link两簇成员之间的最大距离。
Average / centroid平均 pairwise distance 或 cluster centroid 关系。

停止可以按预先的 cluster 数、cohesion、diameter threshold，或在 dendrogram 上选择切割高度。层次方法的优点是可解释且不必一开始知道 k；缺点是大数据集成本高，对 outliers 和不同大小 cluster 敏感。

7. 选 k、SSE 与层次聚类

Elbow method

对多个 k 计算 SSE 并作图；选择下降速度明显变缓的 bend。SSE 随 k 增大通常不会增加，但 elbow 是 heuristic：可能有多个 elbow，也可能没有清楚 elbow。

Choose the bend where adding another cluster produces a much smaller reduction in SSE.

ApproachStartRepeatStop
Agglomerative每个 point 是一个 cluster按 linkage 合并最近两簇达到指定 cluster 数或所有点合并
Divisive所有 points 在一个 cluster选择 cluster 并拆分达到指定数量/直径/cohesion 条件

8. Association rules / 关联规则

规则写成 X → Y。X 是 antecedent，Y 是 consequent。市场购物篮分析的意思是：购买 X 的交易是否也常购买 Y。

MetricFormulaMeaning
Supportfreq(X) / total transactionsX 出现的频率。
Confidencefreq(X,Y) / freq(X)出现 X 时同时出现 Y 的比例。
Liftsupport(X,Y)/(support(X)*support(Y))相对独立出现的关联强度；1 约独立，>1 正关联，<1 负关联。

9. Apriori：逐层生成与剪枝 / Apriori steps

  1. 从 transaction database 统计 single item candidates C1。
  2. 保留 support 达到阈值的 frequent set L1。
  3. 用 frequent sets 生成更大的 C2、C3……。
  4. 删掉低于 minimum support 的 candidates；Apriori property 是 frequent itemset 的每个子集也必须 frequent。
  5. 从最大 frequent itemsets 生成规则，按 minimum confidence 筛选，可按 lift 排序。
# mental workflow
C1 -> keep support >= min_support -> L1
L1 -> generate candidates -> C2 -> prune -> L2
L2 -> generate candidates -> C3 -> prune -> L3
frequent itemsets -> rules -> confidence -> lift ranking

“Apriori prunes a candidate when its support is below the threshold. A frequent itemset must have frequent subsets.”

10. Association rules 与 Apriori 完整流程

support(X→Y) = count(X∪Y) / N
confidence(X→Y) = support(X∪Y) / support(X)
lift(X→Y) = confidence(X→Y) / support(Y)
  1. 扫描数据库得到 C1 support counts，按 minimum support 得到 L1。
  2. Self-join L1 产生 C2；若 candidate 的任一子集不 frequent，依据 Apriori property 立即剪枝。
  3. 再次扫描计算 C2 support，得到 L2；逐层重复直到 Lk 为空。
  4. 对 frequent itemset F 的每个非空 proper subset A 生成 A → F−A。
  5. 计算 confidence，保留达到 minimum confidence 的规则，再用 lift 判断关联方向与强度。
LiftInterpretation
> 1Positive association：X 出现时 Y 比基准更常出现。
= 1Approximate independence。
< 1Negative association / substitution signal。
英文步骤句型： “First, count the support of one-item candidates. Next, prune candidates below the minimum support. Then generate larger candidates from the remaining frequent itemsets. Finally, keep rules whose confidence reaches the threshold.”

11. Apriori 讲义算例 / Worked lecture pattern

课件的 A–E transaction example 使用 minimum support count = 2、minimum confidence = 50%。下表用于理解每层 candidate 如何被筛选；它属于课程讲义案例，不是去年样题或模拟卷答案。

LevelCandidates and countsFrequent result
C1 → L1A:6, B:7, C:5, D:2, E:1L1={A,B,C,D}；E 被剪掉。
C2 → L2AB:4, AC:4, AD:1, BC:4, BD:2, CE:0L2={AB,AC,BC,BD}。
C3 → L3ABC:2, BCD:1, ACD:0, ABD:0L3={ABC}。

由 ABC 生成规则时，confidence 的 denominator 取 antecedent support：conf(AB→C)=support(ABC)/support(AB)=2/4=50%；而 conf(A→BC)=2/6≈33%。因此方向改变会改变 confidence，即使 union itemset 相同。

关键迁移：先写 numerator 是 union support，再写 denominator 是 antecedent support。Confidence is directional because its denominator is the support of the antecedent.

12. 用 Python 检查手算 / Verification code and output

本课件主要要求理解公式和手算步骤，没有指定必须使用某个 Python clustering/Apriori package。下面代码只用于验证课件计算，不把额外库 API 当成正式考点。

Euclidean distance

import numpy as np

point = np.array([1, 2])
centroid = np.array([4, 6])

distance = np.linalg.norm(point - centroid)
print(distance)
输出 / Output
5.0

先逐坐标相减得到 [-3, -4]，平方和为 25，再开方得到 5。考试手算要写出中间式，不只写最终数值。

更新 K-means centroid

points = np.array([
    [1, 1], [2, 1],
    [8, 8], [9, 8]
])
labels = np.array([0, 0, 1, 1])

new_centroids = np.vstack([
    points[labels == i].mean(axis=0)
    for i in range(2)
])
print(new_centroids)
输出 / Output
[[1.5 1. ]
 [8.5 8. ]]

labels == i 选出属于 cluster i 的 rows；mean(axis=0) 对每个 coordinate 取平均；vstack 把两个新 centroids 叠成 2-D array。

Support、confidence、lift

transactions = 100
count_x = 40
count_y = 10
count_xy = 7

support = count_xy / transactions
confidence = count_xy / count_x
lift = confidence / (count_y / transactions)

print(support, confidence, lift)
输出 / Output
0.07 0.175 1.75

Support 是 7%；confidence 是 17.5%；lift=1.75 表示 X 出现时 Y 的出现率是其基准率的 1.75 倍。Association 仍不等于 causation。

13. 无监督学习剩余正式考点

Clustering familyCourse ideaKey distinction
Exclusive / partitioning每个 object 只属于一个 cluster；K-means 是例子。Hard membership。
Overlapping / fuzzy一个 object 可对多个 clusters 有不同 membership degree；fuzzy C-means 是例子。Soft membership。
Hierarchical建立 parent/child nested clusters，并用 dendrogram 表示。不必一开始固定最终 k。
Density-based连接 high-density regions，以 sparse regions 分隔 clusters，可发现 arbitrary shapes。能把 isolated points 视为 noise；varying density/high dimension 较困难。
Distribution model-based假设数据由若干 probability distributions 生成，根据属于每个 distribution 的概率分组。结果依赖 distribution/model assumptions。

Good clustering 与停止条件

  • Good clustering 追求 high intra-cluster similarity 与 low inter-cluster similarity；结果受 representation、distance measure、algorithm 与 implementation 影响。
  • Agglomerative 可在达到预定 k、下一次 merge 会导致 low cohesion、或新 cluster diameter 超过 threshold 时停止。
  • Diameter 是一个 cluster 中任意两点之间的 maximum distance。
  • Unsupervised data 更容易获得，但因为没有 known target，评价与解释通常更困难，结果也不保证代表真实类别。

Apriori 补充

  • 课件描述 Apriori 使用 breadth-first、level-wise 搜索，并可借助 hash tree 计算 candidates。
  • 若 threshold 以比例给出，minimum support count = support threshold × number of transactions；实际使用时需满足规定的整数计数规则。
  • Apriori property：frequent itemset 的每个 subset 都 frequent；等价逆否是含有 infrequent subset 的 candidate 必须被剪掉。
  • Support 衡量普遍程度，confidence 是条件可靠度，lift 用基准频率校正 confidence；association 不等于 causation。

14. 应用、优点与限制

MethodApplications in slidesLimitations
K-meansnews grouping、customer segmentation、recommendation、image grouping、anomaly exploration需预先选 k；对 initial centroids、outliers、scaling 敏感；偏好近似 spherical clusters。
Hierarchicaltaxonomy、biology/genetics、document/customer hierarchy计算和存储成本高；早期 merge/split 通常不可撤销；对 noise/outliers 敏感。
Association rulesmarket basket、recommendation、medical diagnosis、protein sequences低 thresholds 会产生大量规则；高 support 不代表 causation；需结合业务解释 lift。
