1. 编译器与解释器案例 / Compiler and interpreter case

把程序看成一份食谱：compiler 先把整份食谱翻译成机器能执行的步骤；interpreter 一边读一边执行。linker 把不同模块和库接到一起。

Source code
程序员写的代码
→
Compiler
整体翻译
→
Object code
翻译结果
→
Linker
连接库和模块
→
Executable
可执行程序
练习：如何用英文解释？

写两句，必须出现 before execution 和 during execution。

参考组织：“A compiler translates the whole source program before execution. An interpreter translates and executes code step by step during execution.”

2. Python 代码追踪 / Code tracing

考试遇到代码时，用四列草稿：line、variable state、condition、output。不要凭直觉直接看最后一行。

values = [4, 1, 3]
values.sort(reverse=True)
total = 0
for value in values:
    if value == 1:
        continue
    total = total + value
print(values)
print(total)
先做：写出两行输出，并说明 sort、continue 和 total 的变化。

检查点：sort changes the original list；continue skips the current iteration；每次循环后更新 total。

英文框架：“First, the list is sorted in descending order. The loop skips ___. Therefore, the final value of total is ___.”

def greet(name="Joe"):
    return "Hello, " + name

message = greet("Mia")
print(message)

Describe it with: “The function uses a default parameter, but the call supplies an explicit argument.”

3. NumPy 案例 / Array case

这个例子同时练习 shape、axis、广播和 Boolean mask。

import numpy as np
a = np.array([[1, 2, 3],
              [4, 5, 6]])
print(a.shape)
print(a.sum(axis=0))
print(a + np.array([10, 20, 30]))
print(a[a % 2 == 0])
Line读法 / Reading method
a.shape先数 rows 和 columns。
sum(axis=0)沿行压缩，保留每列的结果。
a + vectorvector 被 broadcast 到每一行。
a[mask]只保留 mask 为 True 的元素。

英文模板：“The array has ___ rows and ___ columns. Axis 0 produces one sum per column. Broadcasting adds the vector element-wise to every row.”

4. Pandas 缺失值与筛选 / DataFrame case

df = pd.DataFrame({
    "Name": ["Ana", "Ben", "Chen"],
    "Score": [68, None, 82],
    "Absent": [False, True, False]
})
column_missing = df.isnull().sum()
missing_rows = df[df.isnull().any(axis=1)]
selected = df.loc[df["Score"] >= 70, ["Name", "Score"]]

先判断每一行返回什么结构：isnull() 产生 Boolean DataFrame；sum() 对列聚合；any(axis=1) 产生每一行一个 Boolean；.loc[mask, columns] 同时筛行和筛列。

“The first expression counts missing cells by column. The second creates a row mask: a row is selected if any column is missing. The last expression keeps rows with a score of at least 70 and returns only two columns.”

6. 搜索算法案例 / Search case

假设图的边为 S→A、S→B、A→C、B→G、C→G。练习的目标是说明“队列/栈/代价”怎样改变扩展顺序。

BFS

按 depth level 扩展；先写 queue，再把 children 放入 queue。

DFS

沿一条最深路径走；先写 stack 或当前 path，再回溯。

Uniform cost

每次选择累计 path cost 最小的候选。

A*

给每个候选写 g(n)、h(n) 和 f(n)=g+h。

英文答题框架

“BFS expands nodes by increasing depth. DFS follows one deepest path. Uniform-cost search chooses the lowest path cost, while A* combines the path cost and heuristic estimate.”

7. 专家系统案例 / Rule reasoning case

Facts:
    rainy
    cold

Rules:
    IF rainy THEN bring_umbrella
    IF cold AND rainy THEN wear_coat

Forward chaining 从 rainy、cold 开始，匹配规则并产生新事实；backward chaining 若目标是 wear_coat，就反过来寻找需要证明的条件。

“The knowledge base stores facts and rules. The inference engine applies the rules. Forward chaining is data driven; backward chaining is goal driven.”

9. K-means 与 Apriori 案例 / Unsupervised cases

K-means

给定 k 后，先选 centroids；计算距离并分配；对每簇取 mean 更新；直到 assignment 不变。手算题要写每个点到每个中心的距离。

Apriori

先数单项 support，保留 L1；组合成 C2、剪枝得到 L2；从 frequent itemsets 生成规则，再检查 confidence 和 lift。

英文句型：“First, ___. Next, ___. Finally, the algorithm stops when ___.”
