Week 2 补充：NumPy、SciPy 与 Pandas

NumPy 课件纠错 / Slide correction

原材料写法： np.arrange()
正确写法： np.arange()。它类似 Python 的 range；非整数区间或需要固定点数时优先使用 np.linspace(start, stop, num)。
import numpy as np

a = np.arange(0, 10, 2)       # [0, 2, 4, 6, 8]
b = np.linspace(0, 1, 5)      # five evenly spaced values, endpoint included
np.random.seed(7)              # reproducible random sequence
r = np.random.randint(0, 10, size=(2, 3))

Vectorization 的原因：array 元素使用同质 dtype，因此 NumPy 可对整块数据运行相同操作，避免 Python 循环中不断检查类型。

OperationShape ideaExam sentence
concatenate沿已有 axis 接合，维度数通常不变。“Concatenate joins arrays along an existing axis.”
stack增加一个新 axis。“Stack combines arrays along a new axis.”
split按份数或 break indices 拆分。“Split is the inverse idea of concatenation.”
argsort返回排序位置，不返回排序值。“Argsort returns the indices that would sort the array.”

SciPy 的具体案例 / Concrete scientific tasks

Integration

quad 计算一元积分。例如 ∫₀¹ 10x dx = 5。dblquad 计算二重积分。

Fourier transform

fft 把信号从 time domain 转到 frequency components；ifft 进行逆变换。

Linear algebra

linalg 处理 inverse、linear systems、eigenvalues 等。矩阵 B 是 A 的 inverse 时，AB=I。

Optimisation

minimize 寻找使函数最小的输入，例如 (x-3)^2 的最小点是 x=3。

Interpolation

根据已知数据点构造其间的新值；属于“inside known range”的估计。

Curve fitting

寻找最贴合数据的函数参数。课件弹簧案例：y(t)=A cos(ωt+φ)，拟合 A、ω、φ。

Pandas 的三种 DataFrame 创建方法

pd.DataFrame(np.array([[1, 2], [3, 4]]), columns=["x", "y"])
pd.DataFrame({"x": [1, 3], "y": [2, 4]})
pd.DataFrame([[1, 2], [3, 4]], columns=["x", "y"])

loc 始终按 explicit label；iloc 始终按 integer position。Series 切片后原 index 会跟着 value 保留，不会自动重新编号。Iris 课件案例用 summary statistics 观察：petal length/width 可帮助区分 species。

MYCIN 与 shallow/deep expert systems

MYCIN

1970s Stanford medical expert system，使用约 600 条 IF–THEN rules 和 certainty factors 诊断血液感染并推荐 antibiotics。它未投入临床实践，课件给出的原因是 ethical concerns。

Shallow vs deep

Shallow system 使用 surface knowledge 和 rule-based heuristics；deep system 包含 causal/model knowledge，并结合 rule-based 和 model-based reasoning。

Expert-system strengthExpert-system limitation
一致地应用规则；保存稀缺专家知识；帮助非专家；不会忘记提问。缺少 common sense/creativity；知识库或 inference engine 错误会传播；不能自动适应变化；构建成本高。

PyKE fact 类型：case-specific facts 在 inference engine reset 后清除；universal facts 保留。Pattern variable 以 $ 开头并可绑定；anonymous variable 以 $_ 开头且不保留绑定结果。

Week 4 补充：课件代码纠错与模型工作流

训练/测试代码的现代正确写法

课件旧写法： from sklearn.cross_validation import train_test_split

现代写法： from sklearn.model_selection import train_test_split

课件的 serial slicing 例子也有 off-by-one 和二维 iloc 语法问题。正确写法如下。

nrows = len(dataset)
cut = int(nrows * 0.8)
train = dataset.iloc[:cut, :]
test = dataset.iloc[cut:, :]

X = dataset.iloc[:, :-1]
y = dataset.iloc[:, -1]

课件中的 dataset.iloc[:, ncols] 会越界，因为最后一列位置是 ncols-1，可直接写 -1。

混淆矩阵为什么比 accuracy 更完整

课件案例：90 个 healthy、10 个 unhealthy。若模型把全部人都预测为 healthy，accuracy 仍是 90%，但所有真正 unhealthy 的样本都漏掉。此时 positive class 的 recall 为 0。

precision = TP/(TP+FP)   |   recall = TP/(TP+FN)   |   F1 = 2PR/(P+R)

模型选择：linear regression 预测 continuous target；logistic regression 输出 sigmoid probability 并用于 binary classification；random forest 通过 multiple trees + bagging 提高稳定性；KNN 按距离，需要注意 scaling；SVM 最大化 margin，kernel 包括 linear、polynomial、RBF、sigmoid。

Week 6 补充：手算 K-means、层次聚类与 Apriori

K-means medicine worked example

课件数据：A=(1,1)、B=(2,1)、C=(4,3)、D=(5,4)，k=2，初始中心 c1=A、c2=B。

PointDistance to ADistance to BInitial assignment
A(1,1)01Cluster 1
B(2,1)10Cluster 2
C(4,3)√13 ≈ 3.61√8 ≈ 2.83Cluster 2
D(5,4)5√18 ≈ 4.24Cluster 2

第一次更新：c1=(1,1)；c2=((2+4+5)/3,(1+3+4)/3)=(11/3,8/3)。重新分配后 B 会移到 Cluster 1，得到 A/B 与 C/D 两组；再更新到 c1=(1.5,1)、c2=(4.5,3.5)，随后 membership 稳定。

Hierarchical linkage worked example

课件距离矩阵中最小距离是 d(A,B)=1，所以先合并 A 和 B。

  • Single link: d({A,B},C)=min(2,2)=2；d({A,B},D)=min(2,5)=2；因此 C、D 可在 level 2 接入，E 在 level 3 接入。
  • Complete link: d({A,B},C)=max(2,2)=2；之后 D 与 {A,B,C} 的 complete distance 为 5，E 最后在 6 接入。

Single link 看最近的一对，容易产生 chaining；complete link 看最远的一对，更偏好紧凑 cluster。

Apriori worked example

课件示例给出 L1 counts：A=6、B=7、C=5、D=2；minimum support count=2。L2 保留 {A,B}=4、{A,C}=4、{B,C}=4、{B,D}=2；L3 只保留 {A,B,C}=2。

RuleConfidence calculationAt 50% threshold
{A,B} → Csupport(ABC)/support(AB)=2/4=50%Strong
{B,C} → A2/4=50%Strong
{A,C} → B2/4=50%Strong
A → {B,C}2/6≈33%Not strong
B → {A,C}2/7≈29%Not strong
C → {A,B}2/5=40%Not strong

Density-based clustering 把高密度区域连接成任意形状 cluster，但 varying density/high dimension 可能困难。Distribution model-based clustering 假设数据来自某种概率分布，例如 Gaussian mixture models。
